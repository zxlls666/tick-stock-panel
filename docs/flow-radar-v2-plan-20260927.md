# 日频盘后雷达 V2 预注册方案

> 状态：**Phase C 已完成**。两条 V2 都是 `historical_rejected`。报告见 `docs/flow-radar-v2-historical-20260927.md`。公式、成本、5 日持有期和门槛保持冻结。
> 制定日期：2026-09-27
> V1基线：`docs/flow-radar-phase3-20260927.md`
> 数据基线：行情截至`2026-09-24`，generation `78ff1e8ffb6c48ccb0ebacd0ac780718`

## 1. Go / No-Go

- **最终判断**：No-Go，不继续推进本V2。两条均为`historical_rejected`。
- **不允许的解释**：V2不是把六条信号调到通过，也不是推翻V1失败结论。
- **V1保留结论**：六条V1均未通过预注册的费后5日做多门槛。
- **V2保留结论**：缩量后强收盘扩张V2未形成做多候选；高位换手弱收盘风险V2未形成回避或降权候选。
- **后续规则**：本V2公式、成本、5日持有期和门槛保持冻结；新假设必须另建V2.1并重新预注册。
- **Phase 4～6**：继续暂停。外部事件、分钟或Level-2若重新立项，必须有独立业务目标或新假设，不能用于事后修饰V1/V2结果。

## 2. 为什么不直接调六条参数

V1已经暴露三个问题：

1. 六条信号混合了“做多候选”和“风险标签”，却使用了同一个正收益门槛。
2. 门槛的`n`按个股事件计数，同一交易日的大量股票并非独立样本，几十万条事件会放大统计确定性。
3. 放量滞涨和缩量后扩张出现正均值、负中位数、胜率不足50%的右尾结构；只追均值容易把少数极端赢家误判为稳定优势。

V2先修正研究问题和统计单位，再考虑更多数据。

## 3. V2目标

### 3.1 做多目标

判断“缩量整理后出现放量且强收盘”是否能形成稳定的5日费后正收益，而不是仅由少数右尾样本抬高均值。

### 3.2 风险目标

判断“高位异常换手并弱收盘”是否能稳定预测未来5日相对同日、同市值组股票的负超额收益。它是回避/降权信号，不按做多胜率评估。

## 4. 固定研究口径

除非另立V2.1文档，以下口径在看到V2结果后不得修改：

- 信号收盘后可见。
- 下一交易日开盘成交。
- 主持有期：5个交易日。
- 辅助披露：1、10、20日；不得用辅助周期替换失败的5日主门槛。
- 往返成本：19bp，即佣金万二双边、卖出印花税万五、滑点5bp双边。
- 停牌、一字涨停买入、一字跌停卖出和路径缺口沿用V1规则。
- 行业PIT缺失，仍显示“证据不足/未知”，不得使用当前行业分类回填历史。
- 每个信号日的全部可成交触发股票等权形成一个“信号日组合”。
- 主统计样本数按**可用信号日**计算，不按个股事件行计算。
- 5日持有期导致相邻信号日收益重叠，显著性使用Newey-West，lag固定为4。
- 市值和市场状态仅作稳定性披露，不在结果出来后临时加入主公式。

## 5. V2-L：缩量后强收盘扩张

### 5.1 身份

- **ID建议**：`squeeze_expand_strong_close_v2`
- **名称**：缩量后强收盘扩张V2
- **类型**：做多候选
- **与V1关系**：保留V1“缩量后扩张”五个条件，只增加两个收盘质量条件；V1文件和结论不覆盖。

### 5.2 固定公式

```text
10个交易日前 amplitude_trend_20_60 <= -0.15
AND 10个交易日前 vol_trend_5_60 <= -0.10
AND 当日 vol_ratio_5d >= 1.5
AND 当日 amplitude >= 0.03
AND 当日 vol_regime_5_60 >= 1.2
AND 当日 close_position >= 0.75
AND 当日 change_pct >= 0.01
```

新增条件的经济含义：扩张日必须收在当日区间上部且至少上涨1%，避免把放量冲高回落或方向不明的扩张视为做多确认。没有增加行业、市场状态或外部事件过滤，减少自由度。

### 5.3 主门槛

历史确认必须同时满足：

1. 可用信号日不少于100日；
2. 5日信号日组合费后均值大于0；
3. 5日信号日组合费后中位数大于0；
4. 正收益信号日比例大于50%；
5. Newey-West t统计量大于1.96，lag=4；
6. 至少3个自然年各有不少于30个可用信号日；
7. 满足上一条的年份中，至少三分之二的年度均值大于0。

中位数是V2新增的硬门槛，用于阻止“少数大赢家抬高均值”再次被判为通过。

### 5.4 辅助披露

- 个股事件数和信号日数；
- 1/5/10/20日均值、中位数、胜率、MFE和MAE；
- 小/中/大市值组；
- 强、偏强、震荡、偏弱、弱市场状态；
- 各年份；
- 每个信号日的股票数量分布，防止少数全市场普遍异动日主导结果。

这些分组不在V2结果出来后提升为新门槛。

## 6. V2-R：高位换手弱收盘风险

### 6.1 身份

- **ID建议**：`high_turnover_weak_close_risk_v2`
- **名称**：高位换手弱收盘风险V2
- **类型**：风险过滤/回避候选
- **与V1关系**：触发公式保持V1不变，改为方向正确的风险评价方法。

### 6.2 固定公式

```text
position_240d >= 0.85
AND turnover_z_60d >= 2
AND close_position <= 0.35
AND amplitude >= 0.04
AND amount_ratio_5d >= 0.5
```

不因V1结果调整阈值。V2的变化是将其作为“未来相对弱势”假设，而不是要求触发后做多赚钱。

### 6.3 同日市值匹配基准

对每个触发股票：

1. 使用信号日`log_float_mv`划分的小/中/大市值三分位；
2. 取同一信号日、同一市值桶、未触发该风险信号且可按同样规则成交的股票；
3. 计算这些对照股票下一交易日开盘至第5日收盘的等权费后收益中位数；
4. 个股风险超额收益 = 触发股票费后收益 − 匹配组费后收益中位数；
5. 同一信号日所有触发股票的风险超额收益等权平均，形成信号日风险组合。

行业不参与匹配，因为没有PIT行业数据。市场状态在同一日期天然一致，只作分组披露。

### 6.4 主门槛

历史确认必须同时满足：

1. 可用信号日不少于100日；
2. 5日信号日风险组合平均超额收益小于0；
3. 5日信号日风险组合超额收益中位数小于0；
4. 超额收益为负的信号日比例大于50%；
5. Newey-West t统计量小于-1.96，lag=4；
6. 至少3个自然年各有不少于30个可用信号日；
7. 满足上一条的年份中，至少三分之二的年度平均超额收益小于0。

通过只表示它可能是回避/降权候选，不表示可以直接做空。A股可融券性、成本和召回风险不在本阶段处理。

## 7. 数据分层与证据等级

### 7.1 历史确认

- 区间：`2021-01-04..2026-09-24`，预热仍从`2020-09-09`开始。
- 作用：可以淘汰V2，也可以把V2升级为“历史研究候选”。
- 限制：V2假设来自已看过的V1结果，因此即使历史门槛通过，也不是完全未见数据上的最终证明。

### 7.2 真正前向验证

- 起点：`2026-09-25`之后实际产生的新交易数据。
- 公式、成本、持有期和门槛在首个前向样本进入前冻结。
- 至少累计120个新交易日，且对应信号至少有60个可用信号日，才出第一份前向判断。
- 前向阶段不要求多年度门槛；它是对历史多年稳定性结论的新增确认，不替代历史年度分析。
- 前向结果未达到样本要求前，页面状态只能是“观察中”。

## 8. 状态机

| 状态 | 条件 | 允许动作 |
| --- | --- | --- |
| `draft` | 规格已写，尚未运行 | 只做测试和代码审查 |
| `historical_rejected` | 任一历史主门槛失败 | 保留报告，不调参；如有新假设另建V2.1 |
| `historical_candidate` | 历史主门槛全部通过 | 加入观察列表，不发布为策略 |
| `forward_observing` | 已冻结并开始接收新数据，样本未满 | 只累计，不改参数 |
| `research_qualified` | 历史通过，且前向方向、均值/中位数和胜负比例一致 | 可进入策略组合验证，仍不自动进入执行层 |

不存在“修改门槛后把同一结果改成通过”的状态迁移。

### Phase D：前向观察（不启动）

两条V2均未通过历史主门槛，因此不进入`historical_candidate`或`forward_observing`，也不启动以下原计划：

- 从`2026-09-25`后的新增数据累计V2前向结果；

- 达到120个新交易日后发布V2前向确认报告。

若未来存在新的经济假设，应另建V2.1；不能以继续累计数据的方式把已历史淘汰的V2转成候选。

## 10. 明确不做

- 不同时对六条V1做阈值网格搜索。
- 不因20日均值较好而把主持有期从5日改成20日。
- 不把风险信号反向包装成已经可做空的策略。
- 不引入当前行业分类进行历史行业中性化。
- 不购买分钟或Level-2数据来提高本轮通过率。
- 不删除或覆盖V1失败报告。

## 11. 最终验收

V2计划完成的证据不是“某条终于通过”，而是：

1. 两个假设、两个方向门槛和统计单位在结果前冻结；
2. V1与V2定义和结果可并存、可追溯；
3. 历史报告无论成功失败都完整保存；
4. 当前数据只能产生历史候选，真正前向数据单独累计；
5. 未通过时停止，不在同一版本内移动门槛。

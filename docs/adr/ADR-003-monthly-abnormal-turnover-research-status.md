# ADR-003: 月频异常换手研究策略的偏差修复与候选状态

- **状态：** 已采纳
- **日期：** 2026-10 (v0.2.3)
- **决策者：** Serge

## 上下文

- 背景：对照本地 A 股交易策略研究报告，把缺失/相近主线落成**可执行、无未来函数**的研究规格，并在有偏数据上做偏差修复与执行现实性验证。候选包括月频异常换手
  `abnormal_turnover_1m_12m`（`mean(turnover, 20) / mean(turnover, 250)`，低值优先）的 `raw` 与 `size_neutral` 两版，以及月频反转 `reversal_monthly`（含五切片变体 `reversal_five_sleeves`）。
- 约束：
  - 数据存在四类偏差 —— 退市幸存者偏差、历史 ST 缺失（当前名称静态过滤是未来函数）、流通股本非 PIT、成交过于乐观（仅拦"一字板"不等于完整盘口）。
  - 学术结论多为**多空**因子收益，本项目只实现**多头**端，不能直接套用论文 alpha。
  - E/P、股息率缺可信 PIT 数据契约；清洗后小市值缺退市样本。
- 可选方案：
  1. 直接用 `legacy`（有偏）口径下最好看的结果发布/替换生产策略。
  2. 只在有偏数据里调参，不做偏差修复。
  3. 走**偏差修复瀑布**重跑，并按分层放行门决定候选状态；未过门者 `pause` / 保持 `research_only`。

## 决策

- 采用偏差瀑布：`legacy → strict PIT 股本 → PIT 历史 ST → 退市恢复 100%/70%/0% → 1000万最保守容量/冲击`，**每阶段重新形成权重并重跑账户，不做事后扣减**；规模中性口径的市值固定为 `log(PIT float_shares × raw_close)`。
- 研究宇宙用逐日 PIT 门：`上市 → 未退市 → ST known → 非 ST → 上市满 6 月 → observation/PIT gate`；退市 212 只以前复权 `adjusted-v2` 行情纳入；**BJ（347 只）因缺 PIT ST fail-closed 排除**。
- **月频反转停止**：加入 PIT ST/退市后 base 由正转负（-64.23%），70%/0% 恢复方向翻转，触发既定停止规则。
- **两条异常换手升级为 `bias_reduced_candidate`**（通过 Phase 1–4 全部门），但**继续保持 `research_only`**，不进入公开选股或生产。
- 容量/冲击：以 `t-1` ADV20 participation + 平方根冲击建模；**日线执行只称 `queue_proxy`**（optimistic/base/conservative 确定性边界），不声称 Level-2 排队概率。
- E/P、股息率、清洗后小市值在拿到可信 PIT 数据前**不实现、不发布**。

## 理由

- 有偏数据下的高收益不可发布（PIT ST/universe 修正一项就带来约 -63~-75pp 的系统性高估）；必须先修正到可解释再判定候选状态。
- 分阶段重跑（而非事后扣减）使每个候选的结论可复算、可审计。
- 多头端不能套用多空 spread；无微观数据时只能给日线代理，措辞必须诚实。

## 后果

- 正面：得到两条经偏差修复的候选、一条被证伪的候选；口径与产物可追溯（`manifest` + 瀑布产物，输入/输出 SHA-256）。
- 负面 / 边界：
  - 两条候选仍 `research_only`；BJ PIT ST 缺失、queue 为日线代理、退市复权尚未与生产 enriched 完全对齐。
  - 异常换手换手率高（单边约 8.3–8.7×），容量有限：1 亿最严场景未成交率约 87%/86%。
  - 2026 年截至 9 月两条均为负（raw -3.97%、size-neutral -4.97%），不构成当前持续有效的证据。
- 需要后续验证：前端 BJ PIT ST、Level-2 排队数据、退市独立复权因子统一后再评估；样本外观察见 ADR-004。

## 替代方案否决理由

- **直接发布 `legacy` 结果**：含未来函数与幸存者偏差，PIT ST/universe 修正后系统性高估，不可发布。
- **只在有偏数据里调参**：把偏差当成 alpha，参数与结论都不可迁移。
- **事后按比例扣减收益**：不重新形成权重，掩盖方向翻转，不可审计；改为按阶段重跑。

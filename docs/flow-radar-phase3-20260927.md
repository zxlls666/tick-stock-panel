## 1. 规则

规格在 `backend/app/services/flow_radar.py`。缺文件时写入 `data/user_data/custom_signals/{id}.json`，已有文件不覆盖。计算走现有 `custom_signals` 的 AND 表达式，列名是 `csg_*`。因子和涨跌停沿用评分物化、`compute_indicators`、`compute_limit_signals`。

页面在信号库的「盘后雷达」。接口 `GET /api/custom-signals/radar`。证据、历史统计和风险标签都在这次响应里，刷新会按同一表达式重算。

可解释分数是主条件相对阈值的倍数，每一列截断在 3 后再平均。分数到 3 之后，更极端的样本不再拉开。

成交额增幅是 `amount_ratio_5d`，已经减去 1。量比 `vol_ratio_5d` 是倍数，不减 1。涨跌幅和振幅是比值，0.01 表示 1%。换手率列是百分数口径：成交量（手）× 10000 / 流通股本，2.67 表示 2.67%。

## 2. 事件研究口径

信号在收盘后可见。买入用下一交易日开盘，卖出用之后第 1、5、10、20 个交易日的收盘。路径必须落在市场交易日序号上，中间缺行情的样本不进入该持有期。

最大有利波动是持有期内最高价相对买入开盘，最大不利波动是最低价相对买入开盘。另给一条收盘到收盘的价格路径，那一列不含成交假设。

往返成本 = 佣金万二双边 + 卖出印花税万五 + 滑点 5bp 双边 = 19bp。费后收益 = 开盘到收盘的成交收益 − 19bp。胜率是费后收益大于 0 的比例。

可成交规则与日线回测撮合相同：下一交易日不存在则不可买；成交量为 0 且价格不动视为停牌；一字涨停不买；一字跌停不卖。涨跌停价走 `compute_limit_signals`。ST 标记来自当前证券名称，历史 ST 区间未知。

市值用信号日 `log_float_mv` 的全市场三分位。缺失记为未知。市场状态用信号日 `regime_history.state`，标签是强、偏强、震荡、偏弱、弱。行业没有 PIT 列，`ext_hy_ths` 也没有分区，记为证据不足/未知。

样本来自当前股票 enriched。退市是否完整保留，这次没有单独复核。

研究门槛在看结果之前写死，调用方不能按结果改：

- 持有期固定为 5 个交易日
- 可成交且能卖出的样本 ≥ 100
- 费后均值 > 0
- 费后胜率 > 50%
- 至少 3 个样本不少于 30 的年份，其中正收益年份占比 ≥ 2/3

过不了就记「未显示稳定的费后优势」。更长持有期的均值只作披露，不拿来改门槛。

## 8. 结论

六条日频雷达都没有通过费后 5 日研究门槛。放量突破和异常承接在市值分组里方向一致，方向是负的。其余几条要么均值接近 0，要么均值和中位数、胜率互相打架。

Phase 4 的公开事件、Phase 5 的分钟、Phase 6 的 Level-2 先停。日频代理没有给出稳定的费后优势，不拿更细的数据去补这一轮。

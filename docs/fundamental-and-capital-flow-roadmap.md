# 基本面研究与资金异动监控：现状总结及待实现计划

> 状态日期：2026-09-27
> 状态约定：【现状】为已核验的数据或能力；【计划】为尚未实现的工作。
> 本文中的“资金异动”“疑似吸筹/派发”均为量价统计代理，不代表确认了资金身份或操盘事实。

## 1. Go / No-Go

| 目标 | 判断 | 原因 |
| --- | --- | --- |
| 基本面筛选、候选因子研究和受控回测 | **Go** | 财务四表、公告日、历史股本、日线行情和因子研究链已具备 |
| 日频盘后“资金异动雷达” | **已完成，研究门槛未通过** | 六条代理信号已接入信号库并完成费后事件研究；5日均未显示稳定优势，只保留为描述性观察工具 |
| 宣称已得到完全无偏、跨周期稳定的基本面Alpha | **No-Go** | 退市股日K、历史ST、PIT行业、历史指数成分和长期基准仍不完整 |
| 判断“具体机构/量化资金正在操盘某只股票” | **No-Go** | 缺少账户身份、逐笔委托、逐笔成交和Level-2订单队列；即使补齐Level-2通常也只能识别行为模式 |
| Phase 4公开事件、Phase 5分钟和Phase 6 Level-2 | **Pause** | 不为V1失败结果事后追加数据或移动门槛；允许按独立假设、新版本和预注册验证协议重新立项 |

## 2. 目标结果

在不复制第二套行情、因子或回测系统的前提下，形成两条可验证的研究闭环：

1. **基本面研究闭环**：财务数据按公告日进入因子计算，生成候选因子，经TSP现有检验、挖掘和策略回测链验证。
2. **资金异动研究闭环**：使用日频量价和历史股本生成“异常成交/换手/承接/突破/派发风险”等代理信号，展示证据并进行事件研究。

最终页面和报告必须明确区分：

- 数据事实；
- 规则计算结果；
- 统计推断；
- 尚无法确认的资金身份。

### 3.3 可直接研究的基本面主题

当前可用于候选研究的方向包括：

- 盈利能力：ROE、ROA、毛利率、净利率；
- 成长：收入、营业利润和净利润增速；
- 现金流质量：经营现金流与净利润匹配程度；
- 偿债能力：资产负债率、流动性指标；
- 营运质量：应收账款、存货、资本开支变化；
- 规模和估值：历史流通市值、规模因子及已有估值字段；
- 组合研究：质量 × 估值、质量 × 动量、基本面改善 × 量价确认。

具体字段必须在实现每个因子前核对财务表实际列和公告日期，不以名称相近代替数据契约。

### 3.4 已实现的资金行为代理

【现状】以下指标已被六条盘后雷达复用，并通过现有因子/`custom_signals`链从行情现算：

- 成交量和成交额相对20/60日均值的异常程度；
- `turnover_ratio_5d`、`turnover_z_60d`；
- `turnover_mean_20d`、`turnover_std_20d`；
- `log_float_mv`及按流通市值调整后的成交强度；
- 连续放量、缩量整理、放量突破、放量滞涨；
- 当日收盘位置、上下影比例、收益/成交效率；
- 个股相对市场或可用行业分组的量价强度；
- 异动发生后的1/5/10/20日远期收益与最大不利波动。

这些指标只能支持“异常行为代理”结论，例如“疑似资金参与增强”，不能输出“某机构已建仓”或“量化资金正在操盘”。六条雷达的费后5日研究门槛均未通过，不能作为已验证的正收益策略信号；完整结果见`docs/flow-radar-phase3-20260927.md`。

## 4. 关键数据缺口及影响

| 缺口 | 主要影响 | 当前处理 |
| --- | --- | --- |
| 完整退市股日K | 幸存者偏差，微盘/困境策略结果偏乐观 | 研究报告必须披露；补齐前不宣称全市场无偏 |
| 历史ST状态 | 无法准确排除当时ST/*ST标的 | 困境、低价、涨停类结论降级 |
| PIT行业分类 | 历史行业排名和行业中性化可能穿越 | 暂不把当前行业映射视为历史事实 |
| 历史指数成分 | 基准和成分内研究可能使用未来成分 | 使用固定可解释股票池，显式记录边界 |
| 长期指数行情不足 | 市场环境分类和超额收益基准较弱 | 暂以可用市场代理为研究级指标 |
| 财报修订版本未完全核验 | 后来修订值可能覆盖原报告期 | 需增加版本/PIT审计；公告日正确不等于修订版本正确 |
| 1分钟及更细行情缺失 | 无法识别盘中成交脉冲、尾盘拉升、VWAP执行特征 | 第一阶段只做盘后日频雷达 |
| 逐笔成交/委托和订单队列缺失 | 无法研究撤单、挂单、拆单和盘口冲击 | 不实现“操盘身份识别” |
| 龙虎榜、两融、大宗、回购、增减持、机构持仓未统一接入 | 缺少公开资金事件证据 | 后续作为事件数据扩展，不混入量价事实层 |

## 5. 实施原则

1. 复用现有Parquet、enriched、因子注册、`custom_signals`和正式回测服务。
2. 不建立第二套行情仓库、因子目录、回测引擎或信号结果事实表。
3. 历史数据必须按`(symbol, date)`进行PIT对齐；最新快照不得进入历史回测。
4. 缺失数据保持空值/中性，不能自动解释为看多或看空。
5. 信号名称统一使用“异常”“疑似”“代理”“风险”，禁止把概率判断包装成资金身份事实。
6. 先完成可回测的日频闭环，再决定是否购买或接入分钟、逐笔和Level-2数据。
7. 涉及全市场多年聚合时放在服务端完成，不通过提高前端读取行数上限解决。
8. 每个新因子先建立定义、依赖、方向、预热窗口和最小行为测试，再进入挖掘。

### Phase 3：日频资金异动雷达MVP

**目的**：使用现有数据提供盘后异常行为监控，不推断具体资金身份。

**首批信号建议**：

1. **异常换手**：60日换手率Z分数显著升高；
2. **放量突破**：成交额/换手放大且价格突破阶段区间；
3. **放量滞涨**：高成交强度但收益效率低；
4. **高位换手风险**：高价格位置、异常换手和长上影共振；
5. **异常承接**：高成交额、盘中下探后收盘位置较强；日线只能做粗代理；
6. **缩量整理后扩张**：波动与成交先收缩、随后同步放大。

**任务**：

- [x] 为每个信号写明公式、阈值、预热窗口、证据列和失效条件。
- [x] 优先通过现有因子和`custom_signals`实现，不修改核心源码。
- [x] 输出候选股票、触发日期、各组成指标和可解释分数。
- [x] 使用正式回测/事件研究计算未来1/5/10/20日收益、胜率、最大有利/不利波动。
- [x] 按市值、市场环境和可用行业分组检查稳定性。行业 PIT 缺失，记为证据不足/未知。
- [x] 将涨跌停、停牌、次日不可成交和交易费用纳入可交易性验证。

**退出条件**：信号页面展示的是“触发证据 + 历史统计 + 风险标签”，且任一信号都能从原始行情重新计算，不持久化第二套触发事实。

## 7. 最终验收标准

### 基本面研究

- 因子值按公告日/PIT生效；公告日前不可见。
- 缺失值不自动填零，不被解释为正负信号。
- 因子通过现有批量检验和嵌套样本外验证。
- 报告披露退市、ST、行业PIT、财报修订和样本周期边界。
- 回测结果可由指定数据generation和因子版本复现。

### 资金异动雷达

- 每条提示显示原始证据、规则和触发日期。
- 不使用“主力确认”“机构建仓确认”“量化操盘确认”等无数据支持的表述。
- 至少包含未来收益、最大不利波动、样本数、年份稳定性和可交易性检查。
- 信号可从行情和因子定义重算，不建立不可追溯的第二事实源。
- 数据不足时输出“证据不足/未知”，不强行分类。
